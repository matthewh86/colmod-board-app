Connect to the board

The board lives in a private GitHub repository. Paste a fine-grained token that can reach only that repository (Contents: read and write) and has an expiry date. It is kept in this browser only.

Answers, notes, priorities, epics, moves and card order are saved to the board straight away and reach Obsidian on both PCs within about a minute.
